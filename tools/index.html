Authoring

Everything for adding an article, in one place. All tools run in your browser; nothing is uploaded.

No password is set, so anyone with this address can open the authoring tools. Add an AUTHORING_PASSWORD secret in the repository settings (see docs/AUTHORING.md) and redeploy.

  • Article editor

    Build an article sentence by sentence: Welsh and English side by side, tooltip builder, live preview and a zip to download.

    Start here for a new article.

  • Sync tool

    Tap along to the audio to create timings.json so sentences highlight as it plays.

    After the text and audio are ready.

  • Format checker

    Paste article.md and article.en.md to find formatting problems and line mismatches.

    For files written by hand or edited outside the editor.

Usual order

  1. Write or paste the text in the editor, add glosses and the English line for each sentence.
  2. Time the audio with the sync tool and download timings.json.
  3. Download the zip from the editor, put the folder in content/articles/ and commit. The site rebuilds itself.
